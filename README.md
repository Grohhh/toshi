                      # 🏠 Информационная система "Заселение в студенческое общежитие"
                      
                      ## 📋 Описание
                      
                      Система предназначена для автоматизации работы студенческого общежития. 
                      Приложение позволяет вести учет жилого фонда,  управлять проживающими 
                      студентами, формировать очередь на заселение и создавать необходимую 
                      отчетность.
                      
                      ### ✨ Возможности
                      
                      | Модуль | Функции |
                      | 🏢 **Жилой фонд** | Корпуса, этажи, комнаты, учет мест |
                      | 👨‍🎓 **Студенты** | База данных, поиск, активация |
                      | 📋 **Проживающие** | Заселение, выселение, переселение |
                      | ⏳ **Очередь** | Заявки, приоритеты, заселение |
                      | 📄 **Договоры** | Создание, нумерация, статусы |
                      | 📊 **Отчеты** | 6 типов отчетов, экспорт в CSV |

                      ## 📦 Установка
                      
                      ### 1. Требования
                      
                      - Python 3.10 или выше
                      - PostgreSQL 14 или выше
                      - pip (менеджер пакетов Python)
                      
                      ### 2. Клонирование репозитория
                      
                      ```bash
                      git clone <URL-репозитория>
                      cd Negative
                      ```
                      
                      ### 3. Установка зависимостей
                      
                      ```bash
                      pip install -r requirements.txt
                      ```
                      
                      ### 4. Создание базы данных
                      
                      ```sql
                      -- В pgAdmin или через psql
                      CREATE DATABASE dormitory_db;
                      ```
                      
                      Выполните SQL-скрипт создания таблиц:
                      
                      ```bash
                      psql -U postgres -d dormitory_db -f database/create_database.sql
                      ```
                      
                      ### 5. Настройка подключения
                      
                      Откройте файл `database/connection.py` и укажите ваши параметры:
                      
                      ```python
                      psycopg2.connect(
                          host="localhost",
                          dbname="dormitory_db",
                          user="postgres",
                          password="ваш_пароль",  # Измените на ваш пароль
                          port="5432"
                      )
                      ```

                      ## 🎮 Использование
                      
                      
                      1. **Запустите приложение:** `main.py`
                      2. **Войдите** под `admin` / `admin123`
                      3. **Добавьте данные:**
                         - Раздел "Корпуса" → Добавить корпус
                         - Раздел "Этажи" → Добавить этаж
                         - Раздел "Комнаты" → Добавить комнаты
                         - Раздел "Студенты" → Добавить студентов
                         - Раздел "Проживающие" → Заселить студентов
                      4. **Сформируйте отчеты** в разделе "Отчеты"
